44: 2. Executive Summary
45: 
46: The Inventory Management System (IMS), formerly referred to as the Terminal Tracking Application, is a purpose-built standalone web application for Terminal Distributor — a global payment terminal distributor managing serialised payment devices across a worldwide warehouse network. The application serves as the master system of record for terminal serial number states, inventory counts, order management, and cost tracking.
47: 
48: Release 1 is complete and running locally. This document captures the v1.2 updates: a set of R1 patch items identified post-build (UI improvements and label corrections), and the full R2 feature scope including inventory enhancements, cost calculation engine, cost analytics, and all previously planned planning and integration modules.
49: 
50: Technology stack: React + Vite frontend with e2open teal green (#1A6B7B) navbar, Python FastAPI backend, SQLite (local) upgradeable to PostgreSQL, Tailwind CSS.

118: 4. Objectives
119: 
120: Serial-Level Whereabouts: Monitor location and status of every terminal by serial number at all times.
121: Inventory Overview: Real-time counts of terminals by product and by location across all states.
122: Cost Tracking: Track activity costs per terminal (per state transition) and aggregate cost totals, normalised to reporting currency.
123: Cost Analytics: KPI dashboards for accumulated cost per terminal, cost by location, cost by product family, and repair cost analysis.
124: Inventory Planning (R2): Identify locations where terminals are missing or in overflow; support repositioning.
125: Collaboration: Enable Supply Planner, Warehouse User, Repair Centre, and Supplier to collaborate on a single record.
126: Repositioning Planning (R2): Allow planning of terminal transfers between warehouses.
127: KPIs & Analytics: Dwell times, repair times, transit times, order fulfilment rate, return rates, cost metrics.
128: Return & Repair Management: Full return and repair lifecycle at serial number level including Scrap/End of Lifecycle.
129: Available-to-Promise: Instant ATP confirmation on outbound orders.
130: Purchase Prediction (R2): Forecast new purchase orders from suppliers.
131: Master Data Management: All reference data managed by Admin with Excel upload support.
