581: 9. R2 Functional Requirements — New Items
582: 
583: This section specifies the 6 new R2 items identified post R1 build. Original R2 features (Demand Planning, Supply Planning, Repositioning, Purchase Prediction, Work Orders, Claims, Alerting) retain their specifications from PRD v1.1 Section 8.
584: 
585: 9.1 Inventory: Latest Date & Latest Location Column
586: The All Terminals inventory view is enhanced with two new columns:
587: Latest Date: The date and time of the most recent state history entry for the terminal (i.e., the date of the last state change). Displayed in the user's local timezone.
588: Latest Location: The location code associated with the most recent state history entry. Column header explicitly labelled 'Latest Location' to distinguish from the current location field.
589: Both columns are sortable and filterable as part of the column filtering feature (see 9.3). They are also included in the Excel export of the All Terminals view.
